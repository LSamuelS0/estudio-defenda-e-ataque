# Plano de evolução do Estúdio

## Objetivo
Transformar as ferramentas atuais em um aplicativo integrado de edição de sprites, frames, animações, personagens, equipamentos e partículas para Defenda e Ataque.

## Fase 1 — Base estável
- [x] Preservar os módulos originais.
- [x] Mapear páginas, recursos e pontos de entrada.
- [x] Verificar sintaxe dos scripts JavaScript.
- [x] Criar execução por servidor local.
- [ ] Testar manualmente cada módulo e registrar problemas.
- [ ] Criar backup/versionamento dos projetos do usuário.

## Fase 2 — Estrutura compartilhada
- [ ] Definir formato portátil de projeto.
- [ ] Padronizar personagem, slots, peças, ossos/pontos de encaixe e camadas.
- [ ] Padronizar animação, timeline e keyframes.
- [ ] Padronizar emissores e partículas.
- [ ] Criar biblioteca central de assets e metadados.

## Fase 3 — Interface integrada
- [ ] Painel de projeto e navegação unificada.
- [ ] Visualização de eventos do personagem em tempo real.
- [ ] Painel de status e atributos.
- [ ] Inventário visual e slots de equipamento.
- [ ] Equipar/remover/trocar peças sem perder animações.
- [ ] Pré-visualização por direção, pose e animação.

## Fase 4 — Ferramentas de produção
- [ ] Editor de frames e spritesheets.
- [ ] Timeline com keyframes, curvas, FPS e duração.
- [ ] Editor de partículas com emissores e parâmetros.
- [ ] Biblioteca pesquisável.
- [ ] Comparação e restauração de versões.

## Fase 5 — Exportação para Godot
- [ ] Spritesheets e JSON padronizados.
- [ ] Presets de importação para Godot 4.x.
- [ ] Validação de nomes, dimensões, pivôs e frames.
- [ ] Pacotes por personagem, inimigo ou efeito.

## Ordem recomendada
1. Projeto e salvamento.
2. Visualização de eventos do mago.
3. Equipamento modular e painel de status.
4. Timeline e edição de frames.
5. Sistema unificado de partículas.
6. Biblioteca e exportação Godot.
